# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in ZardUI, please report it by:

1. **GitHub** (preferred): open a [private security advisory](https://github.com/zard-ui/zardui/security/advisories/new)
2. **Email**: **gomesluiz.dev@gmail.com**

Please **DO NOT** create public GitHub issues for security vulnerabilities.

### What to Include

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact

## Supported Versions

| Version         | Supported |
| --------------- | --------- |
| 1.0.0-beta.x    | ✅ Yes    |
| < 1.0.0-beta    | ❌ No     |

## Security Best Practices

- Keep ZardUI updated to the latest version
- Use `npm audit` to check for known vulnerabilities
- Follow Angular security guidelines
- Sanitize user input before passing to components
