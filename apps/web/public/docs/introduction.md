# Introduction

Built for Angular developers who value both aesthetics and functionality. ZardUI bridges the gap between beautiful design and practical implementation.

## Why ZardUI?

Finally, a component library that doesn't force you to choose between beauty and functionality.

### Beautiful & Practical

Meticulously crafted components that look stunning out of the box while remaining highly functional and accessible.

### Community First

Built by Angular developers who understand your needs. Real-world solutions to real problems.

### Modern Angular

Leveraging the latest Angular features including standalone components, signals, and best practices.

### Infinitely Customizable

Built with TailwindCSS for seamless customization. Make every component truly yours.

## Powerful CLI

Our command-line interface makes adding components to your project effortless. No more copy-pasting code or hunting through documentation.

```bash
$ npx zard-cli add button
```

### Smart Installation

Automatically handles dependencies, imports, and configuration. Just specify what you need, and we'll handle the rest.

### Project Integration

Seamlessly integrates with your existing Angular project structure. Respects your conventions and coding style.

### Developer Friendly

Clear feedback, helpful error messages, and intuitive commands. Designed to enhance your development workflow, not complicate it.

## AI Ready

Future Ready

ZardUI components are designed with AI development in mind. Clear patterns, consistent APIs, and comprehensive documentation make it easy for AI tools to understand and work with our components.

### Predictable Patterns

Consistent naming conventions, standardized props, and logical component hierarchies that AI can easily understand and generate code for.

### Rich Documentation

Comprehensive examples, clear API references, and usage patterns that provide AI tools with the context they need to generate accurate code.
